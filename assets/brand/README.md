# Halyard brand

| File | What it is |
|---|---|
| `emblem-light.png`, `emblem-dark.png` | Full Halyard emblem (Fleet frame and wordmark) for light and dark backgrounds; the README uses the light one |
| `mark.svg` | Icon-only mark, simplified to read at 32 px. The same drawing is inlined in `web/src/app.tsx` (sidebar) and `web/index.html` (favicon); change all three together |
| `mark-256.png`, `mark-64.png` | The mark as PNG; `mark-64.png` is embedded in the emailed leadership report (Outlook does not render SVG) |
| `favicon.ico` | Browser icon (16, 32, 48) |
| `tray.ico` | Tray icon (16, 20, 24, 32) |

These follow `docs/UNIFIED-UI.md` section 8.
